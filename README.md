# Gerador de Currículo em PDF

Este é um script Python que gera automaticamente meu currículo profissional em formato PDF.

## Funcionalidades

- Gera um PDF profissional e bem formatado
- Links clicáveis para LinkedIn e GitHub
- Seções organizadas para experiência, formação, habilidades e mais
- Design limpo e profissional com cores personalizadas

## Requisitos

- Python 3.x
- FPDF2

## Como usar

1. Clone o repositório
2. Instale as dependências:
```bash
pip install fpdf2
```
3. Execute o script:
```bash
python main.py
```

O arquivo PDF será gerado na mesma pasta do script com o nome "Curriculo_Manoel_Souza.pdf".
